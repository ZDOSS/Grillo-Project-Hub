# Grillo Project Hub Research Pack

This folder is a first-pass research and specification package for a free, open source, hybrid day-one project management suite that sits somewhere between Trello, GitHub Issues/Projects, Taiga, and lightweight Jira usage.

The working assumptions used for this draft:

- Core posture: hybrid from day one, with local-first data principles
- Distribution: hosted PWA and packaged local desktop app sharing the same core product
- Audience: new software engineers, solo builders, small teams, and practical hobby/professional users
- Tone: not "vibe coder themed"; useful, clean, flexible, and welcoming
- Philosophy: free, open source, modular, exportable, privacy-respecting
